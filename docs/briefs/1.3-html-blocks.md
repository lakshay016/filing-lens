## Public interface (`parse/html.py`)

```python
BlockKind = Literal["text", "table", "heading"]

@dataclass(frozen=True, slots=True)
class Block:
    kind: BlockKind
    text: str
    source_line: int = 0            # lxml sourceline of the block's first element; 0 if unknown
    level: int = 0                  # headings only: 1 Item/Part line, 2 all-caps, 3 bold, 4 underline only
    is_list_item: bool = False
    caption: str | None = None      # tables only

class NotHtmlError(ValueError): ...

def extract_blocks(document: bytes | str) -> list[Block]
```

`extract_blocks` raises `NotHtmlError` when the document has no `<html`, `<body`, `<div`
or `<p` tag in its first 20,000 characters (plain-text filings are out of scope).

## Rules, in this order (SPEC §5.3 made concrete)

Parse with `lxml.html` (tolerant). If the document is `bytes`, let lxml detect the
encoding, falling back to UTF-8 then Latin-1.

**1. Remove.** Drop entirely: `script`, `style`, `head`, `title`, comments,
`ix:header` (any element whose tag, lower-cased, is `ix:header`), and any element whose
`style` attribute, with whitespace removed and lower-cased, contains `display:none`.
Keep the tail text of removed elements. Other `ix:*` elements (`ix:nonnumeric`,
`ix:nonfraction`, `ix:continuation`, …) are transparent: their text stays in place.

**2. Tables.** Process innermost tables first. A table that contains another table is
layout. For a table without nested tables, take its cells (`td`, `th`) and their text.
A cell is *empty* if, after stripping whitespace, it is empty or consists only of the
characters `$ % ( ) —  – -`. A non-empty cell is *numeric* if it matches

```
^[\(\-–—]?\s*\$?\s*\d[\d,]*(\.\d+)?\s*%?\s*\)?$
```

The table is a **data table** when it has at least 4 non-empty cells and at least 30%
of them are numeric. A data table becomes one `table` block: for each row, the texts of
its non-empty cells joined with ` | `; a lone `$`, `%` or `)` cell is glued to the
neighbouring number (`$` before, `%` and `)` after) instead of being dropped; rows
joined with `\n`; rows with no non-empty cell are skipped. Its `caption` is the text of
the nearest preceding `text` or `heading` block of at most 200 characters, if one
exists within the two preceding blocks; that block also stays in the list as itself.
Any other table is layout: its cells are treated as ordinary block containers.

**3. Block boundaries.** Block-level tags: `p`, `div`, `li`, `h1`–`h6`, `td`, `th`,
`tr`, `blockquote`, `pre`, `center`, `section`, `article`, `ul`, `ol`, `table`, `body`.
Walk the tree in document order. A block-level element with no block-level descendants
yields one block from all its text. Text that sits directly inside a block-level
element which also has block-level children yields its own block(s), in order. Two or
more consecutive `<br>` end a block; a single `<br>` is a space. A block that came from
an `li`, or whose text starts with a bullet glyph (`•`, `·`, `●`, `▪`, `◦`, `■`, `-` or
`–` followed by a space, or `(a)`/`(1)`/`1.` style markers are **not** bullets), has
`is_list_item = True`. A bullet glyph alone in its own block (common: the glyph in one
table cell, the text in the next) is merged into the following block, which becomes a
list item.

**4. Text cleanup, per block.** Unicode NFKC; non-breaking and other Unicode spaces to
a plain space; curly quotes to straight quotes; collapse runs of whitespace to one
space; strip. Drop blocks that are empty after this.

**5. Page furniture.** Remove a `text` block when any holds:
- it is a lone page number: `^(page\s+)?\d{1,3}(\s+of\s+\d+)?$` or `^[A-Z]-\d{1,3}$`
  (case-insensitive);
- its text, lower-cased, is `table of contents`, `index`, or `back to top`;
- it is at most 80 characters and its *digit-masked* form (every digit run replaced by
  `#`, lower-cased) occurs at least 5 times among the document's text blocks of at most
  80 characters. Exception: never remove a block that matches the Item pattern
  `^\s*items?\s+\d` (case-insensitive), or a block that is a list item.

**6. Headings.** Computed while extracting text, per block: `bold` = every
non-whitespace character lies inside `b`, `strong`, or an element whose style has
`font-weight` of `bold`, `bolder` or a number ≥ 600; `underline` likewise for `u` or
`text-decoration` containing `underline`; `all_caps` = at least 3 letters and no
lower-case letter. A block is a `heading` when it has at most 120 characters, contains
at least one letter, is not a list item, and is bold, underlined, all-caps, or matches
`^\s*(items?\s+\d+[abc]?\b|part\s+[iv]+\b)` (case-insensitive). Level: 1 if it matches
that pattern; else 2 if all-caps; else 3 if bold; else 4. `h1`–`h6` elements are
headings of level 2 unless they match the pattern.

Order of blocks is document order. The function is pure and deterministic.

## Unit tests (`test_html.py`, small inline HTML strings)

One test per rule: hidden element dropped; `ix:header` dropped and `ix:nonnumeric`
unwrapped; numeric-cell regex on `1,234`, `(3,400)`, `$ 12.5`, `12%`, `—`, `Total`;
a 3×3 table of numbers with a label column is a data table and renders as pipe rows
with `$` and `%` glued; a two-cell layout table with paragraphs yields text blocks;
nested tables; caption picked up; double `<br>` splits and single `<br>` does not;
`li` and glyph bullets flagged; glyph-only cell merged into the next block; NFKC and
quote cleanup; page numbers removed; a line repeated five times with changing page
numbers (`Apple Inc. | 2023 Form 10-K | 21`) removed; an Item line repeated five times
kept; bold short line is a level-3 heading; all-caps is level 2; `Item 1A. Risk Factors`
is level 1; a bold 200-character sentence is text; `NotHtmlError` on plain text.

## Fixture tests (`test_html_fixtures.py`)

For each of the four filings:

- Snapshot (`assert_snapshot("html_<name>", ...)`) of a summary, not the whole text:
  number of blocks by kind, number of headings by level, total characters, the first
  60 headings as `(level, text)`, the first 15 table blocks as `(caption, first row,
  number of rows)`, and the SHA-1 of the concatenated block texts.
- Hard assertions: at least 20 `table` blocks; at least one table has a caption; a
  heading matching `item 1a` exists at level 1; no block text contains `display:none`
  or starts with `<`; no text block is a lone page number; extraction takes under 20
  seconds; running twice gives identical output.
- For Exxon: level-1 headings for Items 1, 1A, 2, 7 and 8 exist. (The original line here
  expected a combined `Items 1 and 2` heading; Exxon FY2022–2023 have none.)
