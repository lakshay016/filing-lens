class EdgarConfigError(RuntimeError): ...     # User-Agent missing or malformed

## Behaviour

**User-Agent.** `user_agent` defaults to `get_settings().sec_user_agent`. Validate in
`__init__`: it must be a non-empty string that matches `\S+@\S+\.\S+` somewhere (a
contact email) and contain at least one other word. Otherwise raise `EdgarConfigError`
with the message `FL_SEC_USER_AGENT is not set or has no contact email; see
.env.example`. **The value itself never appears in an exception message, a log line or
`repr`.** Every request sends headers `User-Agent: <value>` and
`Accept-Encoding: gzip, deflate`.

**Allowed hosts.** Only `https://www.sec.gov/` and `https://data.sec.gov/` URLs are
accepted; anything else raises `ValueError` before any request. (The contact email must
never be sent to another host.)

**Rate limit.** One `TokenBucket(rate=8.0, capacity=8)` per client; every attempt,
including retries, calls `acquire()` first. Token bucket: tokens refill continuously at
`rate` per second up to `capacity`; `acquire` takes one token, or computes the wait
until one is available, awaits `sleep(wait)` and takes it. Guard the state with an
`asyncio.Lock` so concurrent callers are served one at a time. The bucket starts full.
The pipeline creates a single client and shares it across workers; that is what makes
the limit global.

**Retries.** Retry on: HTTP 429, 403, any 5xx, `httpx.TimeoutException`,
`httpx.TransportError`. Do not retry other 4xx (404 raises `EdgarFetchError` at once).
At most `max_attempts` attempts in total. Delay before attempt `k + 1` (k = 1, 2, …):
`min(max_delay, base_delay * 2 ** (k - 1)) * (0.5 + rng.random() / 2)` (exponential,
with jitter between 50% and 100%). If the response has a `Retry-After` header with a
number of seconds, use `max(that, computed delay)`, capped at `max_delay`. Sleep through
the injected `sleep`. After the last attempt raise `EdgarFetchError`. Log each retry at
WARNING with the URL, the status and the delay (never the headers).

**Stats.** Count requests sent, retries, bytes received, final failures.

## Tests (`respx`; injected fake clock and sleep; no real waiting)

Use a `FakeTime` helper: `now` float; `clock()` returns it; `async sleep(d)` adds `d`
and records it. Pass it to both the bucket and the client.

1. **User-Agent:** `None`, `""`, `"NoEmail"`, `"a@b.c"` alone → `EdgarConfigError`;
   `"Test Name test@example.com"` works; the header is sent; the exception text and
   `repr(client)` do not contain the address.
2. **Host check:** `https://example.com/x` → `ValueError`, and no request was made.
3. **Rate limit:** 20 sequential `get_bytes` calls against a mock returning 200. With a
   full bucket of 8 and rate 8/s the fake clock must have advanced by at least
   `(20 - 8) / 8 = 1.5` seconds, and in no one-second window of fake time were more than
   16 requests sent (8 burst + 8 refill). Also test `TokenBucket` alone: 8 immediate
   acquires do not sleep; the 9th sleeps 0.125 s.
4. **Concurrent callers:** `asyncio.gather` of 20 calls gives the same total advance.
5. **Backoff:** mock returns 429, 429, 200 → result returned, two sleeps recorded that
   lie in `[0.5, 1.0]` and `[1.0, 2.0]`. Same for 503 and for 403.
6. **Retry-After:** 429 with `Retry-After: 7` → the sleep is 7.
7. **Gives up:** five 500s → `EdgarFetchError` with `attempts == 5`; exactly five
   requests were made.
8. **No retry on 404:** one request, `EdgarFetchError` with `status == 404`.
9. **Timeout:** `respx` side effect `httpx.ReadTimeout` twice then 200 → succeeds.
10. **`get_json`** parses the body.
