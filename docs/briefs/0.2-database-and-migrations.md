## `docker-compose.yml`

One service `db`: image `pgvector/pgvector:pg16`; environment `POSTGRES_USER=filinglens`,
`POSTGRES_PASSWORD=filinglens`, `POSTGRES_DB=filinglens`; ports
`"127.0.0.1:5433:5432"` (a native Postgres already uses 5432 on the author's machine;
bind to loopback only); named volume `filinglens_pg` at `/var/lib/postgresql/data`;
healthcheck `pg_isready -U filinglens -d filinglens` every 2 s, 30 retries. No other
services.

## `db/models.py`

SQLAlchemy 2 declarative (`DeclarativeBase`, `Mapped[...]`, `mapped_column`). Slice-1
tables only; `chain`, `version`, `fact`, `trace` come in slice 2 and must not be
created now. Every table has `id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY`
(except `company`, keyed by `cik`) and `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`.
Text enums are `TEXT` with a `CHECK` constraint, not Postgres enum types.

```
company
  cik            BIGINT PK                       -- integer CIK, no leading zeros
  name           TEXT NOT NULL
  ticker         TEXT NULL
  sic            TEXT NULL                       -- 4-digit string
  sector         TEXT NULL                       -- SIC division name

filing
  cik            BIGINT NOT NULL FK company(cik)
  accession      TEXT NOT NULL UNIQUE            -- with dashes
  form           TEXT NOT NULL
  period_of_report DATE NULL
  fiscal_year    INT NULL
  filed_date     DATE NOT NULL
  accepted_at    TIMESTAMPTZ NULL                -- UTC
  primary_document TEXT NOT NULL
  raw_sha256     TEXT NULL
  raw_bytes      INT NULL
  fetch_status   TEXT NOT NULL DEFAULT 'pending' CHECK in (pending, ok, failed, skipped)
  fetch_error    TEXT NULL
  parse_status   TEXT NULL CHECK in (ok, partial, failed)
  parse_notes    JSONB NULL
  parser_version TEXT NULL
  INDEX (cik, fiscal_year)

paragraph
  filing_id      BIGINT NOT NULL FK filing(id) ON DELETE CASCADE
  item           TEXT NOT NULL
  seq            INT NOT NULL
  heading_path   TEXT[] NOT NULL DEFAULT '{}'
  text           TEXT NOT NULL
  is_table       BOOLEAN NOT NULL DEFAULT false
  n_tokens       INT NOT NULL
  exact_hash     CHAR(40) NOT NULL
  masked_hash    CHAR(40) NOT NULL
  UNIQUE (filing_id, seq)
  INDEX (filing_id, item, seq)
  INDEX (masked_hash)

alignment_pair
  cik            BIGINT NOT NULL FK company(cik)
  old_filing_id  BIGINT NOT NULL FK filing(id) ON DELETE CASCADE
  new_filing_id  BIGINT NOT NULL FK filing(id) ON DELETE CASCADE
  item           TEXT NULL                        -- NULL = whole-document row
  eligible       BOOLEAN NOT NULL

  sim_cosine     DOUBLE PRECISION NULL
  sim_jaccard    DOUBLE PRECISION NULL
  change_intensity_raw DOUBLE PRECISION NULL
  change_intensity     DOUBLE PRECISION NULL

  INDEX (new_filing_id)

alignment_edge
  pair_id        BIGINT NOT NULL FK alignment_pair(id) ON DELETE CASCADE
  label          TEXT NOT NULL CHECK in (unchanged, rollforward, modified, moved, split, merged, added, deleted)
  old_paragraph_ids BIGINT[] NOT NULL DEFAULT '{}'
  new_paragraph_ids BIGINT[] NOT NULL DEFAULT '{}'
  sim            DOUBLE PRECISION NULL
  n_ins          INT NOT NULL DEFAULT 0
  n_del          INT NOT NULL DEFAULT 0
  changed_ratio  DOUBLE PRECISION NOT NULL DEFAULT 0
  cross_item     BOOLEAN NOT NULL DEFAULT false
  INDEX (pair_id)

change_label
  edge_id        BIGINT NOT NULL FK alignment_edge(id) ON DELETE CASCADE
  annotation_label TEXT NOT NULL CHECK in (formatting_reorder, boilerplate_refresh,
                   numeric_rollforward, new_topic, removed_topic, substantive_reword)
  labelled_at    TIMESTAMPTZ NOT NULL
  pass           SMALLINT NOT NULL CHECK in (1, 2)   -- Python attribute name: pass_
  UNIQUE (edge_id, pass)

change_pred
  edge_id        BIGINT NOT NULL FK alignment_edge(id) ON DELETE CASCADE
  model_version  TEXT NOT NULL
  p_cosmetic     DOUBLE PRECISION NOT NULL
  p_rollforward  DOUBLE PRECISION NOT NULL
  p_substantive  DOUBLE PRECISION NOT NULL
  boilerplate    DOUBLE PRECISION NULL
  alert_score    DOUBLE PRECISION NULL

numeric_alert
  edge_id        BIGINT NOT NULL FK alignment_edge(id) ON DELETE CASCADE
  old_value      DOUBLE PRECISION NOT NULL
  new_value      DOUBLE PRECISION NOT NULL
  unit           TEXT NOT NULL                    -- percent | currency | plain
  rel_change     DOUBLE PRECISION NULL            -- NULL when old_value = 0
  context        TEXT NULL                        -- short snippet around the new number

alert
  filing_id      BIGINT NOT NULL FK filing(id) ON DELETE CASCADE
  edge_id        BIGINT NOT NULL FK alignment_edge(id) ON DELETE CASCADE
  numeric_alert_id BIGINT NULL FK numeric_alert(id) ON DELETE CASCADE
```

`UNIQUE NULLS NOT DISTINCT` needs Postgres 15+; write it as a raw
`sa.text`/`postgresql_nulls_not_distinct=True` unique constraint.

## Migration

`migrations/versions/0001_slice1_tables.py`, revision id `0001`, written by hand (use
autogenerate as a starting point if you like, then clean it). First statement:
`CREATE EXTENSION IF NOT EXISTS vector` (no vector column yet; this proves the image has
pgvector). `downgrade` drops the tables in reverse order and leaves the extension.

`migrations/env.py`: take the URL from `get_settings().sqlalchemy_url()` unless
`config.get_main_option("sqlalchemy.url")` was set by the caller (the test fixture sets
it); `target_metadata = Base.metadata`. **Refuse to run** (raise `RuntimeError`) when the
host is not local and the environment variable `FL_ALLOW_REMOTE_MIGRATION` is not `1`;
this is the guard against migrating Neon by accident before slice 2.

## Test fixtures (`tests/conftest.py`)

```python
@pytest.fixture(scope="session")
def db_engine() -> Iterator[Engine]
@pytest.fixture
def db_session(db_engine) -> Iterator[Session]
```

- `db_engine`: take `Settings().test_database_url()` (settings read from the real
  environment here, because CI and the author set `FL_DATABASE_URL`). Assert
  `is_local_database()`; if not, `pytest.exit` with an error: tests never touch a remote
  database. Connect to the server's `postgres` database with autocommit, `DROP DATABASE
  IF EXISTS filinglens_test WITH (FORCE)`, `CREATE DATABASE filinglens_test`, run
  `alembic upgrade head` against it, yield the engine, drop the database at the end.
- If the server cannot be reached: when `FL_REQUIRE_DB=1` fail; otherwise
  `pytest.skip("local Postgres not reachable on ...; run docker compose up -d")`.
- `db_session`: a session inside an outer transaction that is rolled back after the
  test (`join_transaction_mode="create_savepoint"`), so tests do not see each other's
  rows.

## Tests (`tests/integration/test_db.py`, all `@pytest.mark.db`)

- All nine tables exist; `chain`, `version`, `fact`, `trace` do not.
- `SELECT extname FROM pg_extension` includes `vector`.
- Insert a company, a filing, two paragraphs, a pair and an edge with
  `old_paragraph_ids=[id1]`; read them back.
- `fetch_status='bogus'` violates the check constraint.
- Two `alignment_pair` rows with the same filings and `item NULL` violate uniqueness.
- Deleting a filing cascades to its paragraphs and pairs.
- `test_database_url()` ends in `/filinglens_test`.
