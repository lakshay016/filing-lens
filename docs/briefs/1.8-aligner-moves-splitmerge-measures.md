## Engine changes

`align_item` keeps its signature. New internal structure so that the cross-Item step
can run between Stage 3 and Stage 4:

```python
@dataclass(slots=True)
class ItemState:                 # mutable working state for one Item; not frozen
    old: Sequence[Para]
    new: Sequence[Para]
    matches: list[Match]         # 1-to-1 matches so far
    free_old: list[int]          # unmatched old indices, ascending
    free_new: list[int]          # unmatched new indices, ascending

@dataclass(frozen=True, slots=True)
class Match:
    i: int; j: int; sim: float; stage: int; moved: bool

def run_stages_1_to_3(old, new, sim_fn, cfg) -> ItemState
def finish_item(state: ItemState, sim_fn, cfg) -> list[Edge]     # Stage 4, leftovers, sort, validate
def align_item(old, new, sim_fn, cfg) -> list[Edge]              # = finish_item(run_stages_1_to_3(...))

@dataclass(frozen=True, slots=True)
class FilingAlignment:
    item_edges: dict[str, list[Edge]]     # one entry per aligned Item, canonical Item order
    cross_item_edges: list[Edge]          # label "moved", cross_item=True

def align_filing(old_by_item: Mapping[str, Sequence[Para]],
                 new_by_item: Mapping[str, Sequence[Para]],
                 aligned_items: Sequence[str],
                 sim_fn: SimFn, cfg: AlignConfig = AlignConfig()) -> FilingAlignment
```

### Stage 1 change: reserve move candidates

When `cfg.enable_moves` is true, the move candidates returned by `find_anchors` (unique
`masked_hash` matches that are not on the LIS) are **removed from the gaps before
Stage 2** and recorded immediately as matches with `moved=True`, `stage=3`, `sim=1.0`.
When it is false they stay in the gaps as in task 1.7.

Example: old `[p, q]`, new `[q, p]`. Unique matches `p: 0→1`, `q: 1→0`. Sorted by old
index the new indices are `[1, 0]`; the LIS keeps position 1 (`q`, value 0). So `q` is
the anchor and `p` is the move candidate: result `unchanged(q)`, `moved(p)`.

### Stage 3 — moves within the Item (`moves.py`)

```python
def greedy_pairs(S: np.ndarray, threshold: float,
                 allowed: np.ndarray | None = None) -> list[tuple[int, int]]
    # S shape (n, m). Candidates are cells with S >= threshold (and allowed[i, j] if given).
    # Sort candidates by (-S[i, j], i, j). Take each whose row and column are still free.
    # Returns the taken (i, j) in the order taken.
```

After Stage 2, with `free_old` and `free_new` (reserved candidates are not in them):
if both are non-empty and `len(free_old) * len(free_new) <= cfg.max_sim_cells`,
`S = sim_fn(masked of free_old, masked of free_new)`,
`pairs = greedy_pairs(S, cfg.move_threshold)`; each becomes a match with `moved=True`,
`stage=3`. Remove them from the free lists. Over the cell limit: log `ERROR`, skip.

Sorting must be stable and total: build the candidate list with `np.argwhere` (row-major
order, so already ascending in `(i, j)`) and sort with the key `(-S[i, j], i, j)`.

### Cross-Item moves (`align_filing`)

1. `aligned_items` are the Items that are `ok` in both filings, in canonical Item order
   (the caller decides; see Storage). For each, `state[item] = run_stages_1_to_3(...)`.
2. Pool. Old pool = for each aligned Item in order, its `free_old` paragraphs; then all
   paragraphs of Items that are in `old_by_item` but not in `aligned_items`, in Item
   order then `seq`. New pool likewise. `front` is never in either mapping.
3. If both pools are non-empty and within `cfg.max_sim_cells`:
   `S = sim_fn(old pool masked, new pool masked)`; `allowed[i, j] = (item of old i !=
   item of new j)`; `pairs = greedy_pairs(S, cfg.move_threshold, allowed)`.
4. Each pair becomes an `Edge(label="moved", cross_item=True, stage=3, sim=S[i][j],
   diff stats from diff_stats)`, collected in `cross_item_edges` in the order taken.
   Remove the paragraphs from their Item's free lists (when the Item is aligned).
5. For each aligned Item: `item_edges[item] = finish_item(state[item], sim_fn, cfg)`.
   `validate_edges` for an Item must accept that some of its paragraphs are covered by
   cross-Item edges: give `finish_item` the set of keys already consumed.
6. Paragraphs of non-aligned Items that were not moved get **no edge**.

Same-Item pairs are excluded in step 3 because Stage 3 has already taken every
same-Item pair at or above the threshold.

### Stage 4 — split and merge (`splitmerge.py`)

Runs in `finish_item`, after cross-Item moves, when `cfg.enable_splitmerge`.

```python
def containment(part_masked: str, whole_masked: str) -> float
    # multiset containment over whitespace tokens:
    # sum(min(count_part[t], count_whole[t])) / sum(count_part.values()); 0.0 if part is empty

def find_splits(state, sim_fn, cfg) -> list[SplitMerge]
def find_merges(state, sim_fn, cfg) -> list[SplitMerge]
```

Definitions:

- A **host** is a match with `moved == False` whose label would be `modified` (hashes
  differ on both counts). `unchanged`, `rollforward` and `moved` matches are never hosts.
- **Adjacent** means neighbouring list indices within the Item (`j` and `j ± 1`),
  regardless of whether the neighbour is a table.

Split (one old paragraph became two adjacent new ones). For each free new index `j` in
ascending order:

1. Candidate hosts: the match whose new index is `j - 1`, and the match whose new index
   is `j + 1`, if they are hosts and not already used by an earlier split.
2. For a candidate host `(a, j')`: `first, second = sorted((j, j'))`;
   `joined = new[first].masked + " " + new[second].masked`;
   `s2 = sim_fn([old[a].masked], [joined])[0, 0]`; `s1 = host.sim`;
   `gain_micro = round((s2 - s1) * 1_000_000)`;
   `cont = containment(new[j].masked, old[a].masked)`.
   It qualifies when `gain_micro >= round(cfg.split_gain * 1_000_000)` and
   `cont >= cfg.split_containment`.
3. If both neighbours qualify take the larger `gain_micro`; on a tie the one with the
   lower `j'`.
4. Record: remove the host match; `j` leaves `free_new`; emit
   `Edge(label="split", old=(key of a,), new=(key of first, key of second), sim=s2,
   stage=4, diff stats = diff_stats(old text, new[first].text + " " + new[second].text))`.

Merge is the mirror image, run after all splits: for each free old index `i` ascending,
candidate hosts are the matches whose old index is `i ± 1` (still hosts, not used by a
split or an earlier merge); `joined = old[first].masked + " " + old[second].masked`;
`s2 = sim_fn([joined], [new[b].masked])[0, 0]`;
`cont = containment(old[i].masked, new[b].masked)`; emit `merged` with
`old=(first, second)`, `new=(b,)`.

Compare in integer micro-units as written: `0.75 - 0.65` is `0.09999999999999998` in
floating point and would wrongly fail a `>= 0.10` test.

Only 1→2 and 2→1 are handled. A host is consumed by the first split or merge that uses
it.

### Leftovers, labels, order

After Stage 4: remaining matches become 1-to-1 edges. `moved=True` → label `moved`
(with `sim` and diff stats; a moved paragraph may also have changed text, the `sim`
shows it). Otherwise label by hash as in 1.7. Remaining free indices → `deleted` /
`added`. Sort and validate as in 1.7.

## Worked examples (each is a unit test, using `P` and `stub_sim` from 1.7's helpers)

**M1 swap.** old `[p, q]`, new `[q, p]` → `unchanged(q)` stage 1, `moved(p)` stage 3,
`sim = 1.0`.

**M2 moved and reworded.** old `[x, a, y, z]`, new `[x, y, z, a2]`,
`stub_sim({(a, a2): 0.85})` → three `unchanged`, `moved(a→a2)` with `sim = 0.85`. With
`0.79` → `deleted(a)`, `added(a2)`.

**M3 greedy order.** `greedy_pairs([[0.9, 0.85], [0.95, 0.1]], 0.8)` → `[(1, 0), (0, 1)]`.
`greedy_pairs([[0.9, 0.9], [0.9, 0.9]], 0.8)` → `[(0, 0), (1, 1)]`.

**M4 moves off.** M1 with `enable_moves=False` → `unchanged(q)`, `deleted(p)`,
`added(p)` (the ablation baseline needs exactly this behaviour).

**M5 cross-Item.** Item `7`: old `[m0, t]`, new `[m0]`. Item `1A`: old `[r0]`, new
`[r0, t]`. `align_filing(..., aligned_items=["1A", "7"])` → `item_edges["1A"]` =
`unchanged(r0)`; `item_edges["7"]` = `unchanged(m0)`; `cross_item_edges` = one `moved`
with `old=(t in 7)`, `new=(t in 1A)`, `cross_item=True`. No `added`/`deleted` for `t`.

**M6 one-sided Item.** `old_by_item = {"7": [m0, c]}`, `new_by_item = {"7": [m0],
"1C": [c, d]}`, `aligned_items=["7"]` → `c` is a cross-Item `moved`; `d` has no edge;
`item_edges` has only `"7"`.

**S1 split.** old `[x, ab, y]`, new `[x, a, b, y]` where `ab` is the text of `a`
followed by `b`. `stub_sim({(ab, a): 0.70, (ab, a+" "+b): 1.0})` (keys are masked
texts). After Stage 2 the gap is old `[ab]`, new `[a, b]`: DP matches `ab↔a`
(0.70 > τ; `ab↔b` is 0.0). `b` is free and adjacent to host `(ab, a)`: gain 0.30,
containment of `b` in `ab` is 1.0 → `split`, `old=(ab,)`, `new=(a, b)`, `sim=1.0`.

**S2 gain too small.** As S1 with joined similarity `0.79` → gain 0.09 → no split:
`modified(ab→a)`, `added(b)`.

**S3 exactly at the threshold.** Joined similarity `0.80` → gain exactly 0.10 → split.
(This is the micro-unit case.)

**S4 containment too low.** As S1 but `b` shares under 80% of its tokens with `ab` →
no split.

**S5 new paragraph before its host.** old `[ab]`, new `[a, b]` with
`stub_sim({(ab, b): 0.70, (ab, a+" "+b): 1.0})` → DP matches `ab↔b`; `a` is free and
adjacent → `split`, `new=(a, b)` in document order.

**S6 merge.** Mirror of S1: old `[x, a, b, y]`, new `[x, ab, y]` → `merged`,
`old=(a, b)`, `new=(ab,)`.

**S7 host used once.** old `[abc]`, new `[a, b, c]`, host is `abc↔b`, both `a` and `c`
qualify → only `a` (processed first) is absorbed: `split(abc → a, b)`, `added(c)`.

**S8 hosts must be `modified`.** A free paragraph next to an `unchanged`, `rollforward`
or `moved` match is never absorbed.

Extend the property tests of 1.7 to run with both flags on, and add: no key appears in
two edges across `item_edges` and `cross_item_edges` together; `split` edges have their
two new paragraphs adjacent; flipping `enable_splitmerge` off never changes the set of
`moved` edges.

## Document measures (`measures.py`, SPEC §6.4)

```python
def cosine_and_jaccard(old_texts: Sequence[str], new_texts: Sequence[str]) -> tuple[float, float]
def change_intensity_raw(edges: Iterable[Edge], new: Sequence[Para]) -> float
```

- Tokens: `norm_exact(text).split()` for every text, concatenated per side.
- `sim_cosine`: cosine of the two raw term-count vectors (no IDF). `sim_jaccard`:
  `|set_old ∩ set_new| / |set_old ∪ set_new|`. Both `0.0` when a side has no tokens.
  Round to 6 decimals.
- `change_intensity_raw`: sum of `n_tokens` of the new-side paragraphs of edges labelled
  `added`, `modified`, `split` or `merged`, divided by the sum of `n_tokens` of all
  paragraphs in `new`. `0.0` when `new` is empty. `moved` and `rollforward` do not count.

Tests: identical sides → `(1.0, 1.0)`; disjoint → `(0.0, 0.0)`; a hand-computed
three-word case; intensity on a hand-built edge list.

## Storage (`store.py`)

Synchronous SQLAlchemy session. Models are in `filinglens.db.models` (task 0.2).

```python
def company_pairs(session, cik: int) -> list[PairPlan]
def align_pair(session, plan: PairPlan, model: TfidfModel, cfg: AlignConfig) -> PairSummary
def align_universe(session, ciks: Sequence[int], model, cfg, *, force: bool = False) -> list[PairSummary]
```

**Pair planning.** For one company: take filings with `form in ("10-K", "10-K405")`;
group by `fiscal_year`; in a group keep the earliest `accepted_at` (others are noted as
`duplicate_period` and ignored); sort by `period_of_report`; each consecutive two form a
plan `(old, new)`.

**Pair eligibility** (the whole-document row, `item IS NULL`):

| Condition | `exclusion_reason` |
|---|---|
| either filing `fetch_status != 'ok'` | `not_fetched` |
| either `parse_status` is NULL or `failed` | `parse_failed_old` / `parse_failed_new` |
| `(new.period_of_report - old.period_of_report).days` not in `[270, 460]` | `period_gap` |

A non-eligible pair gets one row (`item NULL`, `eligible = false`, the reason) and
nothing else.

**Item rows** for an eligible pair. Item status comes from `filing.parse_notes["items"]`
(task 1.4): `ok`, `short` or `missing` (absent key = `missing`). For every Item code
that is not `missing` on at least one side, in canonical order:

| Old | New | Row |
|---|---|---|
| ok | ok | `eligible = true`; aligned; edges stored |
| missing | any | `eligible = false`, `item_missing_old` |
| any | missing | `eligible = false`, `item_missing_new` |
| short | not missing | `eligible = false`, `item_short_old` |
| ok | short | `eligible = false`, `item_short_new` |

`aligned_items` = the `ok`/`ok` Items. `old_by_item` / `new_by_item` passed to
`align_filing` contain every Item with paragraphs except `front`.

**Writing**, in one transaction per pair:

1. Delete existing `alignment_pair` rows for `(old_filing_id, new_filing_id)` (edges
   cascade).
2. Insert the document row: `sim_cosine`, `sim_jaccard` over **all** paragraphs of each
   filing including `front`, in `seq` order; `change_intensity_raw` over the aligned
   Items together (edges of all aligned Items; denominator = new paragraphs of the
   aligned Items); `change_intensity = NULL`; `idf_version = model.version`;
   `aligner_version = ALIGNER_VERSION`.
3. Insert one row per Item as in the table, with per-Item measures for aligned Items.
4. Insert edges: Item edges under their Item row; cross-Item edges under the document
   row. `old_paragraph_ids` / `new_paragraph_ids` are the `Para.key` values (= database
   paragraph ids). `Edge.stage` is not stored.

`align_universe` skips a pair whose document row already has the current
`aligner_version` and `idf_version`, unless `force`.

Re-parsing a filing deletes its paragraphs; `filinglens.parse.pipeline` (task 1.5)
already deletes the `alignment_pair` rows that involve the filing. Do not add another
mechanism.

## CLI (`align/cli.py`, registered as `fl align`)

```
fl align fit-idf --universe NAME [--min-df 2] [--out data/models/idf_v1.npz]
    Fits on every paragraph (all Items, including front and tables) of every parsed
    filing of the universe. Prints n_docs, number of terms, version. Refuses to
    overwrite an existing file without --force.

fl align run --universe NAME [--cik N] [--force] [--idf PATH]
    Prints one line per pair and a summary: pairs, eligible, excluded by reason,
    edges by label, banded gaps, seconds.

fl align show --accession NEW_ACCESSION [--item 1A] [--label modified] [--limit 20]
    Prints edges of the pair whose new filing is NEW_ACCESSION: label, sim, heading
    path, and the first 200 characters of each side. For eyeballing.
```

`data/models/` is gitignored. The model file is not committed; its `version` string is
stored on every pair row.
