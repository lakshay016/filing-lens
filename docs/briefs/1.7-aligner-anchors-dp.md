## What this task delivers

A pure, deterministic library that aligns the paragraphs of one Item between an old
filing `A` and a new filing `B` using Stage 1 (anchors) and Stage 2 (dynamic
programming in the gaps). No database, no files except the IDF model file, no network,
no randomness. Stages 3 and 4 (moves, split/merge) are task 1.8; this task leaves the
hooks for them.

## TF-IDF (`align/tfidf.py`)

Our own implementation; do not use scikit-learn's vectoriser (it drops unseen terms).

```python
def terms(masked: str) -> list[str]
    # toks = masked.split(); returns toks + [f"{a} {b}" for consecutive a, b]

def term_hash(term: str) -> int
    # int.from_bytes(hashlib.blake2b(term.encode("utf-8"), digest_size=8).digest(), "little")

@dataclass(frozen=True)
class TfidfModel:
    term_hashes: np.ndarray   # uint64, sorted ascending, unique
    idf: np.ndarray           # float64, same length
    n_docs: int
    default_idf: float        # math.log(1 + n_docs) + 1.0, the IDF of a term with df = 0
    version: str              # f"{IDF_VERSION}:{sha256(term_hashes.tobytes() + idf.tobytes()).hexdigest()[:12]}"

    @classmethod
    def fit(cls, masked_texts: Iterable[str], *, min_df: int = 2) -> "TfidfModel"
    def save(self, path: Path) -> None          # np.savez_compressed: term_hashes, idf, meta (JSON string: n_docs, min_df, version)
    @classmethod
    def load(cls, path: Path) -> "TfidfModel"
    def sim_matrix(self, old: Sequence[str], new: Sequence[str]) -> np.ndarray
```

Definitions, exactly:

- A *document* is one paragraph. `N` = number of documents passed to `fit`.
- `df(t)` = number of documents containing term `t` at least once.
- Kept terms: `df ≥ min_df`. `idf(t) = ln((1 + N) / (1 + df(t))) + 1`.
- A term absent from the model has `idf = default_idf = ln(1 + N) + 1` (as if `df = 0`).
  **It is not dropped.** New paragraphs are made of unseen words; dropping them makes a
  new paragraph look similar to an old one.
- Weight of term `t` in a document with count `c`: `(1 + ln c) · idf(t)`. The vector is
  L2-normalised. A document with no terms is the zero vector.
- `sim(a, b)` = dot product, clipped to `[0, 1]`, then `np.round(·, 6)`.

`fit` must work on about a million paragraphs without holding a Python dict of all
terms: for each document take the unique term hashes, append them to a `uint64` buffer;
whenever the buffer exceeds about 20 million entries, reduce it with
`np.unique(return_counts=True)` and merge into the running `(hashes, counts)` pair (merge
= concatenate both, `np.unique` with `return_inverse`, `np.bincount` with weights).

`sim_matrix`: hash the terms of every text in `old` and `new`; build one local column
index with `np.unique` over all hashes that occur (so out-of-model terms get columns
too); look up IDF with `np.searchsorted` on `term_hashes` (miss → `default_idf`); build
two `scipy.sparse.csr_matrix` with L2-normalised rows; return
`np.round(np.clip((XA @ XB.T).toarray(), 0.0, 1.0), 6)`. Shapes `(0, m)` and `(n, 0)`
must work. The value for a given `(a, b)` must not depend on which other texts are in
the call.

The hashes passed are `masked_hash` values. `longest_increasing` is patience sorting,
written out so the tie-break is fixed:

```
tails = []            # tails[p] = position k of the smallest tail of an increasing run of length p+1
prev = [-1] * len(js)
for k, j in enumerate(js):
    p = bisect_left([js[t] for t in tails], j)   # keep a parallel list of tail values; do not rebuild it each time
    prev[k] = tails[p - 1] if p > 0 else -1
    if p == len(tails): tails.append(k) else: tails[p] = k
walk back from tails[-1] through prev, reverse
```

`js` values are distinct here (each hash is unique on both sides), so strict and
non-strict coincide.

## Stage 2 — gap alignment (`align/dp.py`)

```python
def align_gap(S: np.ndarray, tau: float, *, max_cells: int = 160_000, band: int = 50) -> list[tuple[int, int]]
    # S has shape (n, m): similarities of the gap's old paragraphs (rows) and new
    # paragraphs (columns). Returns matched (i, j) pairs, strictly increasing in both.
```

Recurrence, with `score[0][*] = score[*][0] = 0`:

```
match_ok = S[i-1][j-1] >= tau
score[i][j] = max(
    score[i-1][j-1] + (S[i-1][j-1] - tau)   if match_ok,
    score[i-1][j],
    score[i][j-1],
)
```

Traceback from `(n, m)`, in this order of preference, until `i == 0` or `j == 0`:

1. if `score[i][j] == score[i-1][j]` → `i -= 1` (old paragraph unmatched);
2. else if `score[i][j] == score[i][j-1]` → `j -= 1` (new paragraph unmatched);
3. else → record `(i-1, j-1)`, `i -= 1`, `j -= 1`.

The equality tests are exact because each cell is a copy of one of its inputs or a sum
that was computed once; do not use a tolerance. Consequences to keep in mind: a pair
with `sim == tau` is never matched (its gain is 0, so rule 1 or 2 fires), and among
alignments of equal score the one with the lowest indices is returned.

**Band.** If `n * m > max_cells`, only cells with
`abs(j * n - i * m) <= band * max(n, m)` are computed; the others count as `-inf` and
cannot be stepped into. This band always contains `(0, 0)` and `(n, m)` and is connected
for any shape. Log one `WARNING` with `n`, `m`. (A plain `|i - j| ≤ 50` band is
disconnected when the two sides differ a lot in length; do not use it.)

Speed: the unbanded case is at most 160,000 cells; a plain Python double loop over a
NumPy array is acceptable. Because the gap cost is zero, a row can also be computed as
`np.maximum.accumulate(np.maximum(diag_row, up_row))`; use it if you want, but the
traceback rules above must give the same result.

## Word diff (`align/diff.py`)

```python
def diff_stats(old_text: str, new_text: str) -> tuple[int, int, float]   # n_ins, n_del, changed_ratio
```

Tokens = `norm_exact(text).split()`.
`difflib.SequenceMatcher(None, old_toks, new_toks, autojunk=False).get_opcodes()`:
`replace` adds `i2 - i1` to `n_del` and `j2 - j1` to `n_ins`; `delete` and `insert`
likewise. `changed_ratio = round((n_ins + n_del) / (len(old_toks) + len(new_toks)), 6)`,
or `0.0` when both are empty. For a 2-paragraph side, the caller joins the texts with a
single space in document order.

## Engine (`align/engine.py`)

```python
def align_item(old: Sequence[Para], new: Sequence[Para], sim_fn: SimFn,
               cfg: AlignConfig = AlignConfig()) -> list[Edge]

def validate_edges(old: Sequence[Para], new: Sequence[Para], edges: Sequence[Edge]) -> None
    # raises AlignmentError unless every old key and every new key is in exactly one edge,
    # and each edge's shape matches its label (table in SPEC §6.1)
```

`align_item`, step by step. Work with list indices internally; convert to `Para.key`
only when building edges.

1. If `cfg.enable_moves` or `cfg.enable_splitmerge` is true, raise `NotImplementedError`
   (task 1.8 replaces this).
2. `anchors, _ = find_anchors([p.masked_hash for p in old], [p.masked_hash for p in new])`.
   In this task the move candidates are ignored: they stay in the gaps like any other
   paragraph.
3. Gaps. With anchors `(i_1, j_1) < … < (i_k, j_k)`, add sentinels `(-1, -1)` and
   `(len(old), len(new))`. For each consecutive pair the gap is old indices
   `i_a + 1 … i_b - 1` and new indices `j_a + 1 … j_b - 1`. A gap with an empty side
   needs no similarity matrix.
4. For each gap with both sides non-empty: if `rows * cols > cfg.max_sim_cells`, log an
   `ERROR` and leave the gap unmatched; otherwise `S = sim_fn(masked of gap old, masked
   of gap new)` and `pairs = align_gap(S, cfg.tau, max_cells=cfg.max_gap_cells,
   band=cfg.band)`; translate back to list indices.
5. Build 1-to-1 edges for anchors (stage 1, `sim = 1.0`) and DP matches (stage 2,
   `sim = S[i][j]`). **The label comes from the hashes, whatever the stage:**
   `exact_hash` equal → `unchanged`; else `masked_hash` equal → `rollforward`; else
   `modified`. `unchanged` edges get `n_ins = n_del = 0`, `changed_ratio = 0.0` without
   calling `diff_stats`; the others call it.
6. Every old index in no edge → `deleted` edge: `old = (key,)`, `new = ()`,
   `sim = None`, `n_ins = 0`, `n_del = n_tokens`, `changed_ratio = 1.0`, stage 0.
   Every new index in no edge → `added`, symmetric (`n_ins = n_tokens`).
7. Sort edges by `(first new index if the edge has a new side else len(new),
   first old index if it has an old side else len(old))`.
8. `validate_edges(...)`, return.

Preconditions to assert at the top: `seq` strictly increasing in `old` and in `new`;
keys unique within each list.

## Worked examples (turn each into a unit test)

Use the helpers in `tests/unit/align/helpers.py`:
`P(key, text)` → `Para.from_text(key, "1A", key, text)`;
`stub_sim(table: dict[tuple[str, str], float])` → a `SimFn` that returns `1.0` when the
two masked texts are equal, `table[(old_masked, new_masked)]` if present, else `0.0`.

**E1 identical.** old = new = `[p0, p1, p2]`, distinct texts → three `unchanged`, all
stage 1.

**E2 pure insertion.** old `[x, y]`, new `[x, n, y]` → `unchanged(x)`, `added(n)`,
`unchanged(y)`. Order of the returned list: x, n, y.

**E3 pure deletion.** old `[x, d, y]`, new `[x, y]` → two `unchanged`, one `deleted(d)`
at the end of the list.

**E4 rollforward.** old `"Revenue was $1.2 billion in 2022."`, new `"Revenue was $1.5
billion in 2023."` → one `rollforward`, stage 1, `sim = 1.0`, `n_ins > 0`.

**E5 modified.** old `[x, a, y]`, new `[x, b, y]`, `stub_sim({(a, b): 0.7})` →
`modified(a→b)` stage 2 with `sim = 0.7`. With `0.5` instead of `0.7` → `deleted(a)` and
`added(b)` (equality with τ does not match). With `0.49` → the same.

**E6 duplicates are not anchors.** old `[b, x, b]`, new `[b, b, x]` where `b` is the
same boilerplate text. `b` occurs twice on each side, so the only anchor is `x`
(old 1 ↔ new 2). Gap before `x`: old `[b]`, new `[b, b]` → DP matches old 0 ↔ new 0
(lowest index). Gap after `x`: old `[b]`, new `[]`. Result: `unchanged(0↔0)`,
`added(new 1)`, `unchanged(x)`, `deleted(old 2)`. A wrong implementation that anchors on
the first occurrence of a repeated hash gives a different answer; this test must catch
it.

**E7 crossing in a gap.** `S = [[0.2, 0.9], [0.8, 0.1]]`, τ = 0.5 → `align_gap` returns
`[(0, 1)]` (gain 0.4 beats 0.3; the two cannot both be kept in order).

**E8 lowest-index tie.** `S = [[0.9, 0.9]]` → `[(0, 0)]`. `S = [[0.9], [0.9]]` →
`[(0, 0)]`.

**E9 order is forced.** `S = [[0.9, 0.2], [0.3, 0.6]]` → `[(0, 0), (1, 1)]`.

**E10 empty sides.** `align_item([], [])` → `[]`. `align_item([], [n])` → one `added`.
`align_gap` with shape `(0, 3)`, `(3, 0)`, `(0, 0)` → `[]`.

**E11 band.** `n = m = 500`, `S` = identity × 0.9: the band is used (`250,000 > 160,000`)
and the result is the 500 diagonal pairs. `n = 10, m = 30,000`, `S[i][i * 3000] = 0.9`,
else 0: all 10 matches found (this is the case a naive band loses).

**E12 LIS.** `longest_increasing([3, 0, 1, 4, 2])` → positions `[1, 2, 4]`
(values 0, 1, 2; the patience walk-back picks the run ending in the smallest tail). `[]` → `[]`. `[5]` → `[0]`. `[2, 1, 0]` → `[2]`.

## Other unit tests

- `tfidf`: identical texts → exactly `1.0`; disjoint texts → `0.0`; a text against
  itself plus one unseen word is `< 1.0` and lower than against itself plus one very
  common word (this fails if unseen terms are dropped); `save` then `load` gives the same
  `version` and the same `sim_matrix`; result does not change when extra texts are added
  to the call; `fit` with a tiny buffer limit (make the limit a private keyword
  argument) gives the same model as with the default.
- `diff_stats`: equal texts → `(0, 0, 0.0)`; one word replaced in a ten-word sentence →
  `(1, 1, 0.1)`; empty vs five words → `(5, 0, 1.0)`.
- `validate_edges` raises on: a key in two edges; a key in none; `split` with one new
  key; `added` with an old side.

## Property tests (`test_properties.py`, hypothesis)

Strategy: draw 0–25 base paragraphs, each 3–12 words from a 30-word vocabulary (repeats
allowed, so duplicate paragraphs occur). Build `new` from `old` by a random sequence of:
delete one, insert a fresh paragraph, replace one or two words of one, duplicate one.
Use a real `TfidfModel.fit` over `old + new` texts with `min_df=1` as the `SimFn`.

1. **Partition:** `validate_edges` passes (every paragraph in exactly one edge).
2. **Self-alignment:** `align_item(A, A)` is `len(A)` edges, all `unchanged`.
3. **Order:** take the 1-to-1 edges; sorted by old index, their new indices strictly
   increase.
4. **Determinism:** two calls return equal lists, and
   `json.dumps([dataclasses.asdict(e) for e in edges])` is byte-identical.
5. **Threshold:** every `modified` edge has `sim > cfg.tau`.
6. **No change, no loss:** the number of `unchanged` edges is at least the number of
   anchors found by `find_anchors` with equal `exact_hash`.

Settings: `max_examples=200`, `deadline=None`.

## Traps (the lead checks each of these in review)

1. **Anchors from non-unique hashes.** "Unique" means exactly once on *both* sides.
2. **Anchors use `masked_hash`, labels use both hashes.** An anchor whose `exact_hash`
   differs is `rollforward`, not `unchanged`.
3. **Subtracting τ** is what stops weak matches. Any variant that adds raw `sim` matches
   everything it can.
4. **Dropping unseen terms** in TF-IDF. See the test above.
5. **Float comparisons with tolerances** in the traceback change results between runs
   or platforms. Exact equality only; rounding happens once, in `sim_matrix`.
6. **Iterating a `set` or `dict` of paragraphs** to build output. Always iterate lists in
   index order.
7. **A full `len(old) × len(new)` similarity matrix** for a large Item. Compute per gap.
8. **Off-by-one at the sentinels:** the gap before the first anchor and after the last
   one must be aligned too. E2/E3 with the changed paragraph first or last cover it; add
   those variants.
9. **Band shape.** See E11.
10. **Mutating state shared between calls** (module-level caches keyed on text) breaks
    determinism under hypothesis. No module-level mutable state.
