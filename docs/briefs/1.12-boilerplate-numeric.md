Score of a paragraph = the fraction of its *distinct* shingles that appear in filings of
at least `min_other_companies` **other** companies in the same fiscal year. "Other"
matters: the frequency table counts all companies, so a shingle counts when
`n_companies - (1 if this company has it that year else 0) >= min_other_companies`. The
paragraph being scored is by construction in its own company's set, so subtract 1 when
scoring a paragraph of a filing that is in the shingle store, and 0 otherwise; the
scorer takes a flag `in_store: bool = True` for this. A paragraph with no shingles
scores `0.0`. `novelty = 1 - boilerplate`.

`BoilerplateScorer` loads the frequency rows of one fiscal year at a time into a NumPy
sorted array (cache per year) and uses `np.searchsorted`.

With `t1_rag` only (40–60 companies) the pool is small; the summary printed by
`fl changes shingles --universe t1_rag` states the number of companies per fiscal year
so the limitation is visible. Recomputing from `t2_lite` is slice 3.

## Numeric-delta check (`numeric.py`, SPEC §7.4)

```python
Unit = Literal["percent", "currency", "plain"]

@dataclass(frozen=True, slots=True)
class Number:
    value: float          # scale applied: "$1.2 billion" -> 1.2e9; "(3,400)" -> -3400.0
    unit: Unit
    start: int; end: int  # character span in the original text
    raw: str

@dataclass(frozen=True, slots=True)
class NumericChange:
    old: Number; new: Number
    rel_change: float | None     # (new - old) / |old|; None when old == 0
    points: float | None         # new - old, for percent only
    context: str                 # up to 80 characters around the new number

def extract_numbers(text: str) -> list[Number]
def numeric_changes(old_text: str, new_text: str, cfg: NumericConfig) -> list[NumericChange]
def numeric_alerts_for_edge(edge, old_paras, new_paras, cfg) -> list[NumericChange]
```

`extract_numbers` runs on the display text, lower-cased after NFKC, in the same order as
`norm_masked`: first blank out date matches and standalone years (using `DATE_RE` and
`YEAR_RE` from `normalize`), then find `NUMBER_RE` matches. Unit: `percent` when the
match has `%`, `percent` or `per cent` (`basis points`/`bps` → `percent` with the value
divided by 100); `currency` when it has a currency sign; else `plain`. Scale words
multiply (`thousand` 1e3, `million`/`mm` 1e6, `billion`/`bn` 1e9, `trillion` 1e12).
Brackets or a leading minus make the value negative. Skip a number when it is:

- a reference: immediately preceded (ignoring spaces) by one of the words `note`,
  `notes`, `item`, `page`, `pages`, `section`, `rule`, `form`, `level`, `topic`, `asc`,
  `asu`, `exhibit`, `part`, `no`, `no.`, `number`, `tier`, `phase`, `step`, `footnote`;
- an enumeration marker: `(1)`, `(2)` … with nothing but the brackets, value ≤ 20, no
  unit;
- part of a code that `NUMBER_RE` already rejects (`10-K`, `1A`).

`numeric_changes` (the pairing rule):

1. If the two texts' `norm_masked` are not equal token for token, pair by **template**:
   mask both texts, run `difflib.SequenceMatcher(autojunk=False)` over the masked token
   lists, and pair the *k*-th `<num>` of an `equal` block in old with the *k*-th `<num>`
   of the same block in new. Numbers inside `replace`/`insert`/`delete` blocks are not
   paired (the sentence around them changed; the text classifier handles those).
2. If the masked texts are equal (a `rollforward`), every number pairs positionally.
3. Only pairs with the same `unit` are compared. For each pair with `old != new`:
   - `percent`: alert when `abs(new - old) >= cfg.min_percentage_points`;
   - otherwise: alert when `old != 0` and `abs(new - old) / abs(old) >=
     cfg.min_relative_change`; when `old == 0` and `new != 0`, alert with
     `rel_change = None`.
4. `context` = the new text around the number, trimmed to word boundaries.

`numeric_alerts_for_edge`: only for edges labelled `rollforward` or `modified`, and only
when **no** paragraph on either side has `is_table` (tables roll forward every year by
design). Other labels → `[]`.

`fl changes numeric --universe NAME [--cik N] [--force]`: for every eligible pair's
edges, delete and re-insert `numeric_alert` rows (`old_value`, `new_value`, `unit`,
`rel_change`, `context`). Prints counts per company and the 20 largest changes.

## Tests

`test_numeric.py` (exact expectations):

- **The spec's case:** `"One customer accounted for 10% of revenue."` →
  `"One customer accounted for 35% of revenue."` → one change, percent, `points == 25`.
- `10%` → `12%` → no alert (2 points). `10%` → `15%` → alert (exactly 5 points).
- `$1.2 billion` → `$1.6 billion` → alert, `rel_change ≈ 0.333`. `$1.2 billion` →
  `$1.3 billion` → none. `$900 million` → `$1.2 billion` → alert (scale applied).
- Exactly 25% relative change alerts (`100` → `125`); `100` → `124` does not. Guard
  against floating-point error at the boundary (compare with a `1e-9` tolerance in the
  alerting direction).
- Dates and years never alert: `"as of December 31, 2022"` → `"… 2023"`;
  `"in fiscal 2022"` → `"in fiscal 2023"`.
- References never alert: `"see Note 12"` → `"see Note 14"`; `"Item 7"`; `"page 45"`.
- A table paragraph → no alerts whatever the numbers.
- Unit mismatch (`10%` → `$10`) → not compared.
- Negative values `(3,400)` → `(5,100)`.
- `0` → `5` → alert with `rel_change None`.
- A `modified` edge where one sentence was reworded and another kept: only numbers in
  the kept part pair up.
- `25 basis points` → `150 basis points` → percent, 1.25 points → no alert.
- `extract_numbers` spans point at the right substring.

`test_boilerplate.py`: `shingles` on a 7-token text gives 3 values, deterministic;
fewer than 5 tokens → `[]`; write → frequency → score on a tiny synthetic corpus in
`tmp_path` (12 companies share a sentence, one company has a unique one): shared
paragraph scores `1.0`, unique `0.0`, half-and-half between; the "other companies" rule
at the boundary (exactly 10 others vs 9); a year with no data scores `0.0`.

`test_numeric_store.py` (`@pytest.mark.db`): synthetic pair with a `rollforward` edge →
row written; re-run does not duplicate.
