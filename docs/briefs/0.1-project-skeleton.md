## `config.py`

```python
class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", env_file_encoding="utf-8", extra="ignore")

    sec_user_agent: str | None = Field(default=None, validation_alias="FL_SEC_USER_AGENT")
    database_url: str = Field(
        default="postgresql://filinglens:filinglens@localhost:5433/filinglens",
        validation_alias="FL_DATABASE_URL")
    data_dir: Path = Field(default=Path("./data"), validation_alias="FL_DATA_DIR")
    licensed_dir: Path = Field(default=Path("~/filinglens-licensed"), validation_alias="FL_LICENSED_DIR")
    holdings_file: Path = Field(default=Path("./holdings.local.toml"), validation_alias="FL_HOLDINGS_FILE")
    llm_mode: Literal["live", "replay"] = Field(default="live", validation_alias="FL_LLM_MODE")
    gemini_api_key: SecretStr | None = Field(default=None, validation_alias="GEMINI_API_KEY")
    groq_api_key: SecretStr | None = Field(default=None, validation_alias="GROQ_API_KEY")

    def sqlalchemy_url(self) -> str      # rewrites "postgresql://" to "postgresql+psycopg://"; leaves an explicit driver alone
    def test_database_url(self) -> str   # same URL with the database name replaced by "filinglens_test"
    def is_local_database(self) -> bool  # host is localhost, 127.0.0.1 or ::1

@lru_cache
def get_settings() -> Settings
```

Rules:

- `DATABASE_URL` and `DATABASE_URL_UNPOOLED` are deliberately **not** fields. A test
  asserts that setting them in the environment changes nothing on `Settings`.
- No method, `__repr__` or log line may reveal `sec_user_agent` or an API key. Add
  `def describe(self) -> dict[str, str]` returning, for each field, either a non-secret
  value (`data_dir`, `llm_mode`, database host and port only) or the words `set` /
  `not set`.
- `licensed_dir` is only stored; nothing in this task reads the directory.

## `tests/snapshot.py`

```python
def assert_snapshot(name: str, obj: Any) -> None
```

Serialises `obj` with `json.dumps(obj, indent=2, sort_keys=True, ensure_ascii=False)`
plus a trailing newline and compares with `tests/snapshots/{name}.json`. If the file is
missing or the environment has `FL_UPDATE_SNAPSHOTS=1`, it writes the file (and, when it
was missing and the variable is not set, fails with a message saying the snapshot was
created and must be reviewed). On mismatch it fails with a unified diff.
