## `scripts/check_licensed_data.py`

Standard library only, runnable as `python scripts/check_licensed_data.py [--staged]`.

- Default mode checks every file tracked by git (`git ls-files -z`). `--staged` checks
  the files staged for commit (`git diff --cached --name-only --diff-filter=ACMR -z`).
- **Rule 1 — banned extensions** (case-insensitive): `.parquet`, `.csv`, `.sas7bdat`,
  `.dta`. Any such path is a violation.
- **Rule 2 — the string `permno`** (case-insensitive) inside a *data file*. A data file
  is any checked file whose extension is not one of `.py`, `.md`, `.toml`, `.yml`,
  `.yaml`, `.sh`, `.cfg`, `.ini`, `.mako`, `.lock`, and which is not under `.githooks/`.
  Read as bytes; skip files over 20 MB with a warning line; search for `b"permno"` in
  the lower-cased bytes.
- An allowlist constant `ALLOWED_PATHS: frozenset[str] = frozenset()` (exact paths)
  exists for the synthetic CRSP fixture of slice 3. It is empty now.
- Output: one line per violation, `LICENSED-DATA GUARD: <path>: <reason>`, then a
  summary line. Exit code 1 if there is any violation, else 0.
- The script must not open anything outside the repository and must never reference
  `FL_LICENSED_DIR`.

Structure it as importable functions so tests can call them:

```python
def list_files(staged: bool, repo: Path) -> list[Path]
def check_file(path: Path, repo: Path) -> list[str]        # reasons; empty = clean
def main(argv: Sequence[str] | None = None) -> int
```

## Hook

`.githooks/pre-commit` (executable, `#!/bin/sh`): runs
`uv run python scripts/check_licensed_data.py --staged` and exits with its status; if
`uv` is not on PATH, falls back to `python3`.

`scripts/install_hooks.sh`: `git config core.hooksPath .githooks` and prints what it
did. Run it once in the working copy as part of this task (it changes only local git
config).

## Tests (`tests/unit/test_guard.py`)

Each test builds a throwaway git repository in `tmp_path` (`git init`, set a local
`user.name`/`user.email`), so nothing touches the real repository. Load the script with
`importlib.util.spec_from_file_location`.

- A tracked `x.parquet` → exit 1, path in output. Same for `.csv`, `.sas7bdat`, `.dta`,
  and for upper-case `X.PARQUET`.
- A tracked `notes.json` containing `"PERMNO": 10107` → exit 1. The same content in
  `loader.py` or `README.md` → exit 0.
- A clean repository → exit 0.
- `--staged`: a banned file that is staged but not committed → exit 1; a banned file
  that exists on disk but is untracked and unstaged → exit 0.
- A path in `ALLOWED_PATHS` (monkeypatch the constant) → exit 0.
