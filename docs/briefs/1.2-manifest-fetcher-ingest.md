## Index (`edgar/index.py`)

Pure parsing functions plus two fetch helpers that take an `EdgarClient`.

```python
@dataclass(frozen=True, slots=True)
class TickerEntry: cik: int; ticker: str; title: str

@dataclass(frozen=True, slots=True)
class CompanyInfo: cik: int; name: str; ticker: str | None; sic: str | None; sector: str | None

@dataclass(frozen=True, slots=True)
class FilingMeta:
    cik: int; accession: str; form: str
    period_of_report: date | None; fiscal_year: int | None
    filed_date: date; accepted_at: datetime | None      # timezone-aware UTC
    primary_document: str

def parse_company_tickers(payload: Any) -> dict[str, TickerEntry]
def parse_submissions(payload: Any) -> tuple[CompanyInfo, list[FilingMeta], list[str]]
    # third value: names of the older pages listed in filings.files
def parse_submissions_page(payload: Any, cik: int) -> list[FilingMeta]
def fiscal_year_of(period_of_report: date) -> int
def sic_division(sic: str | None) -> str | None
def document_url(cik: int, accession: str, primary_document: str) -> str

async def fetch_ticker_map(client, cache_dir: Path, max_age_hours: float = 24) -> dict[str, TickerEntry]
async def fetch_filing_list(client, cik: int) -> tuple[CompanyInfo, list[FilingMeta]]
```

Facts (verified 2026-11-15):

- `company_tickers.json`: `{"0": {"cik_str": 320193, "ticker": "AAPL", "title": "Apple Inc."}, ...}`.
  When a ticker appears twice keep the first.
- Submissions: `https://data.sec.gov/submissions/CIK{cik:010d}.json`. Top level has
  `name`, `sic`, `tickers` (list) and `filings`. `filings.recent` is columnar: parallel
  arrays `accessionNumber`, `filingDate`, `reportDate`, `acceptanceDateTime`, `form`,
  `primaryDocument` (and others to ignore). `filings.files` is a list of
  `{"name": "CIK0000320193-submissions-001.json", "filingCount", "filingFrom", "filingTo"}`;
  each is fetched from `https://data.sec.gov/submissions/{name}` and is itself one
  columnar object (the same keys as `recent`, at the top level).
- `acceptanceDateTime` looks like `2026-11-03T13:05:15.000Z` and is true UTC. Parse to
  an aware `datetime`. Empty string → `None`.
- `reportDate` may be an empty string → `period_of_report = None`, `fiscal_year = None`.
- `fiscal_year_of(d)` = `d.year - 1` if `d.month == 1 and d.day <= 7`, else `d.year`.
- `document_url` =
  `https://www.sec.gov/Archives/edgar/data/{cik}/{accession without dashes}/{primary_document}`.
- `sic_division`: by the first two digits: 01–09 Agriculture, 10–14 Mining, 15–17
  Construction, 20–39 Manufacturing, 40–49 Transportation & Utilities, 50–51 Wholesale
  Trade, 52–59 Retail Trade, 60–67 Finance, Insurance & Real Estate, 70–89 Services,
  91–99 Public Administration; otherwise `None`.

Keep only forms in `{"10-K", "10-K405", "10-K/A", "10-K405/A", "10-KT", "10-KT/A"}`.
Skip entries with an empty `primaryDocument`. Cache `company_tickers.json` at
`data/cache/edgar/company_tickers.json` and reuse it while younger than `max_age_hours`.
`form.idx` (bulk discovery) is not part of this task.

```python
    # data_dir / "raw" / str(cik) / accession / (primary_document + ".zst")
def write_raw(path: Path, content: bytes) -> tuple[str, int]   # (sha256 hex of the uncompressed bytes, len)

```

zstd level 10. Write to a temporary file in the same directory, then `os.replace`, so an
interrupted run never leaves a half-written file.

## Fetcher (`edgar/fetch.py`)

```python
@dataclass(frozen=True, slots=True)
class IngestSummary:
    companies: int; filings_seen: int; filings_new: int
    fetched: int; skipped: int; failed: int; bytes: int

async def ingest(universe: Universe, session_factory, client: EdgarClient, *,
                 since: int | None = None, limit: int | None = None,
                 concurrency: int = 4) -> IngestSummary
```

1. Resolve CIKs (ticker map + explicit CIKs).
2. For each company: fetch the filing list (all pages), upsert `company`, and upsert a
   `filing` row for each `FilingMeta` whose `fiscal_year` lies in
   `[max(universe.fiscal_year_min, since or 0), fiscal_year_max]` (rows with
   `fiscal_year None` are skipped and counted). New rows: forms in `universe.forms` get
   `fetch_status = 'pending'`; the amendment and transition forms get `'skipped'`.
   Existing rows are left alone except that metadata fields are refreshed; never reset a
   status.
3. Download: select `pending` and `failed` rows of this universe's companies and forms
   (apply `limit` here, ordered by `filed_date` descending). With `concurrency` workers
   sharing the one client: get the document, `write_raw`, set `raw_sha256`, `raw_bytes`,
   `fetch_status = 'ok'`, clear `fetch_error`. On `EdgarFetchError` set `'failed'` and
   store a short `fetch_error` (status and attempt count, no headers). One database
   transaction per filing.
4. Rows already `ok` whose file exists are not requested again; they count as
   `skipped`. If a row is `ok` but its file is missing, set it back to `pending` first.

`universe.store_raw = false` raises `NotImplementedError("text-only mode is task 3.2")`.

## CLI (`edgar/cli.py`)

```
fl ingest --universe NAME [--since YEAR] [--limit N]
    Runs ingest with asyncio.run. Prints:
    companies 5 | filings seen 41 | new 41 | fetched 35 | skipped 6 | failed 0 | 187.4 MB
    Exits 1 if any download failed. Exits 2 with a clear message when FL_SEC_USER_AGENT
    is unset (EdgarConfigError) before any request.

fl universe check NAME
    Loads the file, resolves tickers (uses the cached ticker map; fetches it if needed),
    prints one line per company: ticker, CIK, name, SIC division.

fl universe draft-t1 [--out config/universes/t1_rag.draft.toml]
    Helps the author build t1_rag (SPEC §4): downloads the FinanceBench open-source
    question file into data/cache/financebench/ (not committed; licence CC BY-NC 4.0),
    takes the distinct company names, matches them to SEC tickers, adds the tickers from
    the holdings file (FL_HOLDINGS_FILE, falling back to holdings.sample.toml), and
    writes a draft universe TOML with fiscal_year_min = 2014. Every FinanceBench company
    is listed with a comment showing the SEC title it was matched to; names that could
    not be matched confidently go into a commented block at the end for the author to
    resolve by hand. Nothing is guessed silently.
```

For `draft-t1`: the dataset is public at Hugging Face `PatronusAI/financebench` and in
the GitHub repository `patronus-ai/financebench` (a JSONL file of 150 questions with a
`company` field). Find the current raw-file URL yourself and put it in one constant.
This download does not go through `EdgarClient` (different host): use a plain `httpx`
GET with **no** custom User-Agent, so the SEC contact string is never sent elsewhere.
Matching: normalise both names (upper-case, drop punctuation and the suffixes `INC`,
`CORP`, `CORPORATION`, `CO`, `COMPANY`, `LTD`, `PLC`, `HOLDINGS`, `GROUP`, `THE`); exact
match on the normalised name is confident; anything else is unresolved. The matching
function is pure and unit-tested; the download is not tested.
